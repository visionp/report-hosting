# Browser assets

HTMX 2.0.4 is vendored as htmx.min.js. Source: https://unpkg.com/htmx.org@2.0.4/dist/htmx.min.js
The application serves this file locally. Forms also work without JavaScript.

The Flex Partners brand mark is reused from the user's `flex_accounts` reference
project. The workspace theme uses its forest green, lime accents and light
background. Fonts use the local Inter / Segoe UI / system sans-serif stack.
